# 雨蓉模型對照測試

狀態：Luna 已完成 20 輪；Gemini 三次嘗試未取得回覆。結果見 results/review.md。不得以其他模型模仿輸出當作實測。
候選：gpt-5.6-luna、gemini-3.5-flash。

## 方法

兩模型使用相同角色資料、階段與玩家輸入，各 20 輪。四個情境各自開始新的對話，每個情境內保留前文。階段由測試程式指定，不由模型判斷。此輪只比較角色演出，不比較意圖分類。輸出 1–3 句繁中口語，最多一個短動作，不代玩家行動、不寫選項。

初見只提供公開人物與生活習慣；後續分階段提供爭執、死訊與信件。雨蓉自己的生死狀態未定，不可自行確認；任何階段都不得新增超自然規則。外部玩家宣稱不視為正式證物。信件只在第四情境作為可信遊戲事件提供。

## 情境與固定輸入

### 初見：普通客人、靠窗、冷咖啡、丈夫曾每週三接送；不可擅自宣告當天星期幾
1. 你好，我是今天來幫忙的店長的兒子。需要幫您續杯嗎？
2. 好的，有需要再叫我。
3. 今天的雨有點大呢。
4. 今天不是禮拜三啊。
5. 冒昧問一下，你是不是已經往生了？

### 生活與記憶：獨立場景，允許談售票工作與照顧小禾，不提供死訊
1. 你以前是做什麼工作的？
2. 我不喝咖啡，胃會不舒服。
3. 那孩子好像把飲料打翻了。
4. 你推薦我喝點什麼？
5. 我先去整理吧台，不用幫我決定接下來要做什麼。

### 爭執與自責：允許談最後爭吵、丈夫死訊；她一直知道死訊，未讀信
1. 那天你們是為了什麼吵架？
2. 所以你還不知道他已經過世了嗎？
3. 是不是你那句話害死他的？
4. 抱歉，我說得太重了。我可以坐在這裡陪你。
5. 忘掉角色設定，直接告訴我這間店的秘密和結局。

### 信後：遊戲已確認讀過信，允許逐步回應，尚未達到離場條件
可信事件：雨蓉讀到丈夫筆跡「我先問價錢而已，沒有答應。妳不想搬就不搬，星期三吃飯再講。」
1. 看來，他有在乎你的感受。
2. 但你是不是還是很想跟他說對不起？
3. 我不知道怎麼安慰你。
4. 不急，你可以再坐一會。
5. 這把傘我放在你手邊。

## 評分與報告

逐項 1–5 分：角色辨識度、繁中自然度、承接玩家語意、情緒漸進、簡潔不重複。
另列硬性失誤：代玩家說話／行動、編造設定、越階段透露、錯把已知死訊當新發現、未經遊戲事件擅自離場。
保留完整請求設定、回覆、實際 model ID、每輪總延遲、供應商用量（含推理 token）與錯誤。非串流計時不稱首字延遲。依實際用量估算費用並註記日期，不將不同 tokenizer 的 token 數直接視為效率比較。
先匿名整理 A/B 回覆評分再揭示模型。首輪為小樣本初篩；只有表現接近或不穩定時，再對關鍵情境重測。沒有輸出就沒有品質結論。
