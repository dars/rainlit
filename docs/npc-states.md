# 店內 NPC 的執念與離場規則

狀態：使用者已確認的共用故事規則。若舊文件或原型流程與本規則衝突，以本規則為準。

## 核心因果

**所有困在店裡的 NPC，都必須先鬆開自己的執念，便會自主決定離開咖啡館，進入告別。**

在此之前，他們會卡在執念中留在店裡。這不只是「想走卻出不去」：執念尚未鬆開時，他們根本不會形成真正想離開的意願。不能先讓角色決定走，再把離開當成已釋懷的證明。

## 共用狀態順序

| 狀態 | 角色處境 | 離場限制 |
|---|---|---|
| 困在執念中 | 以原本的心結理解自己與過去，持續留店 | 不產生離開念頭 |
| 執念受到動搖 | 看見線索、回憶或不同理解，但仍可能反駁、退縮 | 仍不產生離開念頭；動搖不等於鬆開 |
| 執念已鬆開 | 不再被原本那個必須完成、彌補或等待的信念困住 | 自主決定離開，進入告別；不立刻消失 |
| 產生離開念頭 | 在鬆開執念之後，自主形成結束等待的意願 | 進入各角色自己的告別過程；仍能回應玩家並表明自己該走了 |
| 完成告別／離場 | 依該 NPC 已確認的方式結束留店 | 不要求所有人都從正門走出去 |

實作時須分開記錄「執念是否鬆開」與「是否產生離開意願」。前者是後者的必要條件，不能用單一 ready 或聊天次數代替兩者。

讀信、取得物件、得知真相、願意談心、玩家安慰、陪坐，以及暫時平靜，都是過程或促成條件，不能單獨等同於執念鬆開。玩家催促或要求離開也不能繞過這項前提。

鬆開執念不代表不再悲傷、想念或遺憾。判定必須有角色理解轉變的劇情依據，不能靠玩家說中某句通關口令，也不能僅靠模型生成一句「我想走了」。每位 NPC 的具體判據仍須另行設計。

## 各角色的對應

- **林雨蓉**：先走出「必須等丈夫回來，收回最後那句氣話」的執念，不再讓那句話代表兩人全部的關係，才會想離開咖啡館。信只是動搖執念的線索；讀信或陪坐不能直接解鎖離場。她可以仍不願搬家，搬家意願與鬆開這個心結是不同的事。
- **陳伯安**：同樣受此共用規則約束。心結與未盡責任、對母親的虧欠有關，沿用角色卡；不能僅因交出鑰匙或玩家表示接班就視為執念鬆開。具體鬆開判據待設計。
- **小禾**：同樣須先鬆開自己的執念，才可能不再留在店裡。沿用其獨立身份與七年存在價值的角色線；告別仍可是在原地逐漸消失，不因本規則改成走出正門。具體意願與鬆開執念的表現待設計。

未來新增的店內 NPC 也遵循本規則，不自行增設例外。

## 原型實作狀態

雨蓉已移除陪坐次數通關，新增 attachment（held / shaken / released）、letterUnderstood、bondRemembered、wantsLeave。讀信後可從信意或平常相處開始；兩者都經過實際對話後，才開放重新理解最後氣話的事件，由雨蓉自己表達不再需要等丈夫回來收回那句話。同一段先呈現理解轉變，再由她自主表達想回去，標記 released、wantsLeave 與 ready（告別中），不再要求玩家額外陪坐；leave 必須同時滿足 released、wantsLeave、ready、傘在桌邊與界線開放。

這是有前置證據的預寫轉折原型，不是模型已能自由評估所有情感理解。玩家不用說中固定台詞，可選建議或以自由輸入表達同一探討意圖；普通安慰、催促或連續陪坐不能替代證據。

舊存檔若 ready 卻無上述條件，退回 processing；已 departed 的歷史結局保留，不把角色強行叫回店裡，欲體驗新結尾可重開。陳伯安前段已可玩，尚未設計可靠的母親立場證据；小禾未實作。兩者仍須依共用規則設計各自心結證據。

## 玩家離店規則

玩家與 NPC 的離場條件分開判定。只要任何一位店內 NPC 尚未完成告別／離場，玩家就不能離開咖啡館；即使雨蓉已離開，也不能把其他客人的故事算作完成。所有 NPC 都完成離場，才解除這項限制。小禾在原地消失也可視為其完成離場，不要求走過正門。

玩家嘗試離開時，停在門前，呈現「留在店裡，回到座位旁」選項。究竟是主角自己不願離開，還是咖啡館使他無法離開，保留模糊；暫不新增鎖門、空間循環等機制設定。這次嘗試不得改變 NPC 的執念、離場意願、持有物品或故事進度。返回首頁只是介面導覽，不代表角色已離開店裡。

原型以 player_leave / stay 和 exitAttempt 處理門前停留；NPC 的 leave 維持獨立。game/cafe.ts 集中檢查三位客人的離場狀態。陳伯安與小禾尚未實作，固定視為尚未離場，因此目前試玩段落結束不會解鎖玩家的故事內離店。未來串接兩位角色的真實進度後，再完成全員離場後的玩家離店結尾。

## 共用告別互動（最新定案）

所有 NPC 都遵循「執念鬆開 → 自主決定離開／告別中 → 完成告別後離場」。告別期間依然會回答玩家、聊天、回應關心，同時自然表明自己該走了。這不是為了留下角色，也不是等待玩家批准；不因聊天恢復執念、不重新坐下等待。不同角色保留自己的口吻及離場方式。

明確且沒有附帶問話的自然送別（如「路上小心」「慢走」）可以完成告別；若玩家同一句仍在問問題，先回答，不以結尾覆蓋問話。曖昧的話先接續對話，並保留送別選項。不能以任意聊天次數強制離場。實作目前套用雨蓉，其餘角色開發時沿用此共用規則。舊存檔已 released 卻尚在 processing，載入後進入告別；已 departed 不倒退。
