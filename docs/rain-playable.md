# 雨蓉篇可玩原型

2026-09-22。首頁開場後可推門進店，體驗雨蓉的短篇互動。這不是最終劇情：信件來歷與母親未能完成告別的原因仍待定。

## 已完成

- 靜態雨蓉桌邊畫面、短對話、固定動作、自由輸入、歷史紀錄、讀過的信與傘的位置。
- TypeScript reducer 控制等候、談心結、讀信、消化、準備離開、已離場；另有戒心與物件狀態。
- 固定按鈕不呼叫 AI。自由輸入由 Luna 一次結構化輸出提供意圖候選與日常台詞；非 chat 意圖的台詞一律丟棄，由 reducer 的固定文案呈現事件。
- Cloudflare Worker 同源 /api/start、/api/load、/api/turn；Next.js 仍靜態匯出，開發時 rewrites 至本機 Worker。
- D1 保存權威狀態與最近 100 則對話；瀏覽器只持有隨機存檔識別碼。識別碼等同此存檔的存取憑證，不提供帳號同步。
- revision 與短期 pending lock 防止同時操作；turnId 保留已提交回應，重送不再呼叫模型、不重複推進。超過 60 秒未完成的 lock 可接手；模型 timeout 為 18 秒。
- 模型失敗或基本台詞檢查不通過時，用原狀態對應的預寫文字接續；自由輸入動作可能未辨識成功，玩家仍可使用明確選項。
- 每 IP 的邊緣速率限制 20 請求/分鐘，每存檔最多 80 次模型呼叫、200 次操作。速率限制不是全域精確預算；有大量公開流量前需再評估濫用與總額控制。

## 限制

意圖分類仍可能誤解語意；世界狀態只能依規則變更，但台詞的語意檢查目前是有限模式檢查，無法保證杜絕捏造。存檔沒有自動清理／帳號恢復，清除瀏覽器資料後不能找回原存檔。pending lock 在極端程序中斷後需等租約到期再重試。前端未處理任意長期跨版本存檔升級。

## 驗證

`node tests/rain-api.mjs` 在本機 Worker 驗證不可能交付、未授權拆信、戒心修復、重送冪等、完整離場、重新載入與不復活。已用瀏覽器檢查桌面/390px 手機顯示、進店、取傘、重整與繼續。已實際呼叫 Luna 驗證日常對話、自由文字交付失敗、提早詢問丈夫死訊；也觀察到一次 fallback 正常顯示預寫回應。這是小樣本，不是自由輸入全覆蓋評估。

## 節奏修訂

使用者試玩回饋：展開過急、尚未交談就出現雨傘選項。現改為六段楔子（回店整理遺物→童年記憶→停業店內燈光→推門→仍有客人→走近窗邊），每段由玩家推進。初見僅有招呼，再詢問續杯，接著聊雨勢或等人。雨蓉提到自己的傘後才解鎖取傘，道具欄也不能提前透露。先聽她談等人，才能邀請深入聊及爭執。這些是敘事事件條件，不是累計任意聊天輪數。

新增 greeted、coffeeAsked、umbrellaKnown、waitingHeard；舊存檔依已取得道具與劇情進度補齊，不回退已完成事件。開場使用獨立 v2 儲存鍵；想看新楔子請選「開始遊戲」。新版可玩順序測試通過；未設定回憶場景美術，當晚場景維持雨夜。
