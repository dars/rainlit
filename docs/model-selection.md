# 雲端說書模型選定與比較紀錄

## 目前決策（2026-09-22 已確認）

採用 **GPT-5.6 Luna（`gpt-5.6-luna`）** 作為遊戲角色對話模型，後續實作以 Luna 為主。Gemini 比較暫停，等使用者之後重新提出再安排，不自動排程或重試。

已完成 [初輪測試](../evals/results/review.md) 與 [狀態機輔助測試](../evals/results-state-v1/review.md)。後者 Luna 完成 14 次生成與 5 次固定節點，Gemini 3.5 Flash 完成 13 次生成，中途三次 503；不得稱兩家都完成整條流程。Luna 的低延遲與較符合狀態的演出支持本次選擇，但仍有語意與格式錯誤。

測試使用 low 推理，暫作實作起點；不是不可調整的最終參數。故事狀態、物件與重要揭露由程式及固定文案控制；自由輸入的意圖分類尚未驗證，不因選定演出模型而宣稱分類已可靠。雨蓉篇網頁原型現已接入 Luna，見 [原型說明](rain-playable.md)。

以下保留早期價格研究與測試構想作歷史資料，不代表仍要繼續比較其他候選。早期 Gemini 3.7 Flash 價格表與實測的 Gemini 3.5 Flash 是不同型號。

## 一局費用示意

假設每局 60 次模型呼叫，每次平均輸入 3,000 tokens、輸出 250 個計費 tokens。

輸入必須包含提示、角色卡、狀態、歷史及玩家訊息，並非只有玩家說的那一句。輸出假設為總計費量；若產生額外推理 tokens，需另外納入。不同模型對相同中文的 token 數也不同。

公式：60 × (3,000 × 輸入單價 + 250 × 輸出單價) ÷ 1,000,000。

| 模型 | 假設每局 USD |
| --- | ---: |
| GPT-5.6 Luna | 0.054 |
| Gemini 3.7 Flash | 0.19125 |
| Claude Haiku 4.5 | 0.255 |
| Claude Sonnet 5 | 0.510 |

這是比較用的固定用量情境，不是遊戲實測成本或上限。未計其他模型呼叫、摘要、重試、額外推理、語音、託管及稅費，也沒有扣除快取優惠。若每輪持續重送完整對話，平均輸入可能遠高於此假設。

## 早期選擇建議與未知事項（歷史提案）

- 建議先比較 Luna 與 Sonnet 5，確認本故事中較高價格是否帶來可辨識的改善；Gemini 與 Haiku 作第二輪候選。這是縮小測試範圍的提案，不是已決定的正式配置。
- 官方文件不能證明誰最適合台灣繁中、生活化對白或本故事的恐怖節奏，不能提前給出品質勝負。
- 官方相對速度描述無法換算成此遊戲的秒數。實測需記錄第一段可見文字時間、整段完成時間，以及較慢請求的表現。
- 較貴模型也可能洩漏或捏造；故事狀態仍由程式控制。
- 不以目前 Codex 對話的試演表現代替候選 API 的表現。

## 早期比較構想（非目前待辦）

使用固定版本的雨蓉角色卡與三個狀態：初见、持傘未讀信、已讀信。每個狀態準備相同的玩家輸入與相同可見事實。

先做固定上下文的單回合比較，以免前一輪回答不同造成後續輸入不同。每個案例重複三次，匿名排序讓使用者閱讀。再對入選者做多回合試玩，檢查記憶、節奏與累積成本。

人工評分：繁中自然度、雨蓉的個性、情感節制、是否接住玩家意思、是否留下互動空間。另行記錄嚴重錯誤：提前揭密、捏造身世、替玩家決定、擅自改變物品／離場狀態。不要讓文筆分數抵銷嚴重設定錯誤。

紀錄每次測試的模型 ID、提示版本、生成／推理設定、請求時間、延遲、實際 token 用量與費用。各家參數不同，不強制套用相同 temperature；採各自支援且適合短對話的設定，完整記錄以便重現。

上述段落為早期構想；API 金鑰設定與實際呼叫現已完成，結果與目前決策以文件開頭為準。
