# 陳伯安完整故事

2026-10-02 使用者確認並接入程式：陳伯安仍在世，是過度自責的老者。這版取代先前病逝、等待死後相見及廚房消失的提案。角色卡見 characters.md 與 characters/owner.runtime.json；實作見 game/owner.ts。

## 店是他生活的重心

陳伯安曾任飯店廚師，腰傷後頂下咖啡館。朋友與熟人大多在這裡。他習慣替人做事，用吩咐表示關心，讓母親的孩子放學留下寫功課，還清出一格櫃子放書包。店裡有事，就該由自己處理，逐漸成為他對自己的要求。

他知道夜裡有特殊客人，但不完全理解。有人滿足後走出門，有人消失。他一直親自接待，習慣讓母親和孩子先回家，沒有把事情說清楚。

## 活下來以後的自責

突發病情讓他住院。他請母親暫代，叮嚀六點前關門，以為自己回去再細說即可。出院後生還，身體卻無法負擔原本的店務，才正式退下來。具體病名與日期留白，不即興添加。

他不是蓄意騙母親接店，也不能以生病免除告知責任。後來母親叫他先把身體顧好、回去休息，他只當作她在客氣。一直保留的備用鑰匙代表：有事還該由他回來處理。

> 本來只叫她替我顧幾天。後來，倒像整間店都成了她的事。

他想問她後來過得如何、有沒有事情還能補上；卻一直把未補好的部分當成不能接受體諒的理由。母親過世後，他更覺得沒有機會交代完。他仍活著、有往後的人生，卻把自己困在未盡責任中。

## 第一段 認出老先生

雨蓉離開後，主角環顧才注意他坐在裡面的桌旁。今晚他帶著備用鑰匙回店；沒有看見進門不等於超自然瞬移。桌上只有菜單，無飲料或報紙。

> 今天是你顧店？……我以前常在這裡。坐吧，不用忙著倒水。

先標為老先生。主角覺得面熟，從書包櫃與放學回憶認出陳伯安。母親死訊可在這段或後面告知，記錄後不重播初聞；談晚年之前必須已告知。

> 她以前總叫我先把身體顧好。我一直覺得，她只是客氣。現在，有些話也來不及問了。

## 第二段 未交代清楚的事

詢問母親何時接手，說出住院、生還與退下來的經過。詢問鑰匙、危險或未盡責任，再逐步承認自己沒有說清楚。

> 沒說清楚，是我的責任。可我越想補好，越不知道該怎麼問她，後來那些年究竟過得好不好。

執念仍在，沒有离開念頭；不能拿走他的鑰匙當成解法，也不能答應接班交換自由。

## 第三段 他沒有看見的生活

玩家分享親見：母親晚年常待到很晚、疲憊，卻也有幸福與滿足。這不是替她宣告原諒。陳伯安起初擔心她在孩子面前沒說苦處，但逐漸承認不能因為自己自責，就抹去孩子看見的那部分。

> 我老想著自己留了多少麻煩，倒沒有好好問過，她那些日子是怎麼過的。

此時只是動搖。他接著說出自己想聽的答案：到底還有什麼能補上？自己是否能真正休息？他已經聽過母親叫他休息，卻沒能接受她也有判斷自己生活的能力。

## 第四段 停止用守店補回過去

前提：責任已說明、玩家晚年見聞已分享且接住、期待回答的心結已談。泛泛安慰、陪坐、催促或一句我原諒你不能略過前提。

> 她以前叫我回去休息，我總覺得，是她不好意思讓我做。……也許她是真的覺得，剩下的事，她能自己決定。
>
> 沒說清楚的，我還是對不起她。可是她後來的日子，不能全讓我的自責說了算。
>
> 有些話再也問不到了。我也不能一直守在這裡，當作還能把過去補好。

他鬆开執念，接著自主表達離意。不是不再難過，也不是確定已被赦免。

> ……我也該回去了。謝謝你願意跟我說她的事。

## 第五段 告別與留下的鑰匙

告別期間仍正常回答問題，不按聊天次數消失，不回到等待。玩家可選自然送別或自由說「路上小心」。附帶問句時先回答，不能用離場覆盖。

明確送別後切至備用鑰匙特寫。他把鑰匙放在吧台旁桌面，不交給任何人。收齊菜單、扶正椅子；這是最後的照顧，不再找工作讓自己留下。

> 這把放這裡就好。也沒什麼非得等我回來處理的了。你不用接。

玩家按「目送他走向店門」後，切換同一位老人的背影。他踏進騎樓，穿過夜雨街燈；不消失在廚房，不是鬼魂。他還有自己的日子要過。

> 你也別一直站著。……又把你當小孩了。

最後「回望店內」回到鑰匙的空景，聽見鉛筆滾落聲，銜接還在店裡的小客人。小禾完整篇未實作，介面如實提示；不把試玩結束當成全員離場。

## 執行狀態與限制

seated → memory → handoff → regret → life → response → ready → key → departed → afterword。
